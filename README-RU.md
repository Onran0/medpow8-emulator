# MedPOW-8 Emulator

---

Данный проект является эмулятором процессора на архитектуре MedPOW-8

Вы можете загружать в него код и подключать порты через
класс Emulator

Также вы можете поставить большую частоту эмулятора,
вплоть до ~10 мГц

## Как использовать эмулятор?

### 1. Получите эмулятор

Вы можете скачать готовый jar эмулятора с вкладки [релизов](https://github.com/Onran0/medpow8-emulator/releases)
или же собрать его самому (про это есть пункт в конце
документации)

Также вам нужно получить jar ассемблера и
добавить его в локальный репозиторий. Как это сделать
можно посмотреть в конце документации.

После этого добавьте jar в локальный репозиторий Maven, после
чего вы сможете его добавить в **pom.xml** следующим образом:

```xml
<dependencies>
    <dependency>
        <groupId>com.github.onran0.medpow8</groupId>
        <artifactId>medpow8-emulator</artifactId>
    </dependency>
    
    ...
</dependencies>
```

### 2. Создайте экземпляр класса Emulator

```java
Emulator emulator = new Emulator();
```

### 3. Загрузите в эмулятор код

Вы можете это сделать через CommandsPipeline, который можно
получить с помощью метода getPipeline()

Вы можете посмотреть все возможные методы для загрузки кода,
среди них имеется:

1. Загрузка машинного кода из файла или массива байт
2. Компиляция исходников в машинный код и загрузка с помощью
первого метода

```java
emulator.getPipeline().assembleAndAddCommands(
        """
        dial 0
        dial 3
        hlt
        """
);

```

### 4. Установите порты

Вы можете сделать это с помощью методов setDial(), setPort() и
setDisplay()

```java
emulator.setDial(b -> System.out.println(b & 0xFF));
```

### 5. Настройте частоту обновления эмулятора

Допустим, вы хотите поставить 5 кГц

```java
emulator.setFreqHz(5000);
```

### 6. Запустите эмулятор

```java
emulator.startLoop();
```

Запуск эмулятора блокирует текущий поток. Эмулятор будет обновляться
по указанной частоте до тех пор, пока вы его не отключите с помощью
метода terminate(). Также системными свойствами можно настроить
автоматическое отключение эмулятора при вызове `hlt` из программного кода

Включить такое поведение можно добавив данную строчку в аргументы JVM:

`-Dmedpow8.terminateOnHalt=true`

## Проблемы

На данный момент эмулятор не поддерживает команды копирования
флагов в регистры или память, а также не поддерживает копирование
регистра выбранного порта. Это обусловлено тем, что ассемблер и
дизассемблер на данном этапе находятся в бета версии, и сами не
поддерживают вышеупомянутые команды. Постепенно с обновлением
ассемблера данные команды будут поддерживаться.

## Как собрать эмулятор?

### 1. Получите medpow8-assembler

Вы можете также скачать готовый jar ассемблера с вкладки
[релизов](https://github.com/Onran0/medpow8-assembler/releases) на его репозитории, или собрать самому по
инструкции в его репозитории.

### 2. Добавьте jar ассемблера в локальный репозиторий Maven

### 3. Склонируйте репозиторий medpow8-emulator

### 4. Настройте проект

Добавьте свою конфигурацию запуска и список артефактов

### 5. Соберите эмулятор и добавьте в локальный репозиторий Maven
